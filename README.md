📝 Todo App

A simple and responsive Todo App built using HTML, CSS, and JavaScript. This project is designed to practice frontend web development fundamentals, including structuring web pages, styling interfaces, and implementing interactive functionality.

🚀 Features

* Add new tasks
* View your task list
* Simple and clean user interface
* Responsive design
* Interactive functionality using JavaScript

Note: Update this section as you implement each feature.

🛠️ Tech Stack

* HTML5 — Structure of the application
* CSS3 — Styling and layout
* JavaScript — Application logic and interactivity
* Git & GitHub — Version control and project hosting

⚙️ Getting Started

1. Clone the repository

git clone <YOUR_GITHUB_REPOSITORY_URL>

Replace <YOUR_GITHUB_REPOSITORY_URL> with your actual GitHub repository URL.

2. Navigate to the project directory

cd Todo-App

3. Run the application

Open index.html in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
